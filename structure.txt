# VerbyFlow - Project Structure

## Project Overview
VerbyFlow is a real-time multilingual voice communication platform built with Vue.js and FastAPI.

## Key Technologies

### Frontend
- Vue.js 3 with Composition API
- Vuex 4 for state management
- Vue Router for navigation
- WebRTC / WebAudio API for audio handling
- WebSockets for real-time communication

### Backend
- Python 3.9+
- FastAPI framework
- WebSockets for real-time data
- Whisper (OpenAI) or similar for STT
- Argos Translate or cloud APIs for translation
- Coqui TTS or similar for speech synthesis
- Uvicorn as ASGI server

## Development Workflow
1. Set up local development environment
2. Start backend API server
3. Start frontend development server
4. Work on features independently or full-stack
5. Test with real-time audio communication

## Deployment Options
- Docker containers for easy deployment
- Cloud hosting (AWS, GCP, Azure, etc.)
- Separate frontend/backend deployments possible
- Environment variables for configuration

## API Endpoints

### REST
- `/api/users` - User management
- `/api/languages` - Available languages

### WebSocket
- `/ws/call/{call_id}` - Main call communication
